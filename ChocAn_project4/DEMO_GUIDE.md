# Demonstration guide — about 8–10 minutes

Use a clean working copy for the demonstration. Do not remove an existing data file unless you mean to discard those saved demo records. The final submission ZIP starts without saved member/provider records.

1. **Login and roles (about 45 seconds).** Run the application. Try `manager` with a wrong password, then log in as `operator` / `op123`. Point out that operator, provider and manager credentials open different menus.
2. **Member/provider CRUD (about 2 minutes).** Add member `100000001`, Alex Member, `1 Main St`, Tuscaloosa, AL, 35401. Add a second member `100000002`, Sam Member, using another valid address. Add provider `200000000`, Dana Provider, `3 Main St`, Tuscaloosa, AL, 35401, Counselor, `demo@example.com`. Edit the first member's name and provider's name. For both delete operations, use separate temporary records (e.g., member `100000009` and provider `200000009`) so the primary demo records remain. List the records to show the results. Use operator option 10 to suspend member `100000002`.
3. **Validation and service recording (about 2 minutes).** Log out and log in as `provider` / `pr123`. Show the directory. Validate unknown member `999999999`, suspended member `100000002`, and active member `100000001`. Record a service for the active member using today's actual date in YYYY-MM-DD format, service code `100001`, confirmation `Y`, and a short comment. Its fee is $75.00. Record a second service with code `100002` ($40.00), for a total of $115.00. Show an invalid service code being rejected if time allows.
4. **Accounting and manager reports (about 2 minutes).** Log in as `manager` / `mg123`. Run accounting, pressing ENTER for both dates to include the last seven calendar days. Show the summary: one paid provider, two consultations, $115.00 total. Open the generated member/provider report files and `eft.csv`. Separately request all three report types using manager options 2, 3, and 4. Show the provider directory option.
5. **Persistence (about 45 seconds).** Log out, type `EXIT`, and fully relaunch the application. Show the saved members/providers and run the same summary. The total remains $115.00.
6. **Classes and contributions (about 1–2 minutes).** Show the final UML. `Main` wires one shared `DataStore` into the managers. `Login` produces a `User` with a `Role`. Menus call their corresponding controllers. `ServiceManager` checks membership and the service catalog, then saves a `ServiceRecord`. `ReportGenerator` filters those records by date and formats the reports; `Accounting` creates the complete set. Describe each teammate's actual contribution and explain your own work.

The PDFs do not explicitly require everyone on camera, but the team chat mentions possible additional Slack instructions. Check that instructor message when deciding the recording format.
